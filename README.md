# SoundOS releases

Installers and the update feed for SoundOS, a macOS menu bar audio controller.

- Download the latest `SoundOS-<version>.dmg` from [Releases](https://github.com/anhtran110501/SoundOS-releases/releases/latest), open it and drag SoundOS to Applications.
- Installed copies check `appcast.xml` daily and offer new versions through Sparkle.

The first launch on a Mac may be blocked by Gatekeeper; allow it in System Settings › Privacy & Security › Open Anyway.
